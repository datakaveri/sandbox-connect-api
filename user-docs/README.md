# Sandbox Connect User Docs

This folder contains the user-facing documentation site for Sandbox Connect.

## Requirements

- Node.js 18 or newer
- npm

The current development machine has an older Node runtime, so install/build should be run in an environment with Node 18+.

## Commands

```bash
npm install
npm run start
```

Build production assets:

```bash
npm run build
```

The docs site copies OpenAPI artifacts from the repository root `docs/` directory into `user-docs/static/openapi/` before start/build:

```bash
npm run sync:openapi
```

## OpenAPI Source

The source OpenAPI files are generated by Swag in the root repository:

```bash
PATH=/usr/local/go/bin:/home/tgdex/go/bin:/usr/bin:/bin \
  /home/tgdex/go/bin/swag init -d cmd/api,pkg/constants -g main.go -o docs --parseGoList=false
```
