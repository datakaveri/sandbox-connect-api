# Sandbox Connect User Docs

This folder contains the user-facing documentation site for Sandbox Connect.

## Requirements

- Node.js 18 or newer
- npm

The current development machine has an older Node runtime, so install/build should be run in an environment with Node 18+.

## Commands

```bash
npm install
npm run start
```

Local development and production both default to `baseUrl=/user-docs/`, so the local site opens at `http://localhost:3000/user-docs/docs/intro`.
The site URL and base URL can still be overridden with `DOCS_SITE_URL` and `DOCS_BASE_URL`.

Build production assets:

```bash
npm run build
```

The docs site copies OpenAPI artifacts from the repository root `docs/` directory into `user-docs/static/openapi/` before start/build:

```bash
npm run sync:openapi
```

## Deployment

### Prerequisites

- Node.js 18+ and npm (install via [nvm](https://github.com/nvm-sh/nvm) if not available)
- The OpenAPI spec must be generated before building (see **OpenAPI Source** below)

### Build

```bash
# 1. Install dependencies
npm install

# 2. Generate the production static site (outputs to build/)
npm run build
```

`npm run build` automatically runs `sync:openapi` first, copying the latest
`swagger.yaml` / `swagger.json` from `docs/` into `static/openapi/`.

### Serve

The `build/` directory contains plain static files — serve them with any web
server (nginx, Apache, S3 + CloudFront, etc.).

**nginx example:**

```nginx
server {
    listen 80;
    server_name docs.example.com;
    root /var/www/sandbox-connect-docs/build;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

Copy `build/` to the web root and reload nginx:

```bash
cp -r build/ /var/www/sandbox-connect-docs/build
sudo systemctl reload nginx
```

### Quick sanity check

```bash
# Preview the production build locally before deploying
npm run serve
# Opens at http://localhost:3000
```

## OpenAPI Source

The source OpenAPI files are generated by Swag in the root repository:

```bash
PATH=/usr/local/go/bin:/home/tgdex/go/bin:/usr/bin:/bin \
  /home/tgdex/go/bin/swag init -d cmd/api,pkg/constants -g main.go -o docs --parseGoList=false
```
